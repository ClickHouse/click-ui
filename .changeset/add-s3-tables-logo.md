Adds the Amazon S3 Tables logo to the click-ui logo set.

The component is `AWS_S3_TABLES_ICEBERG`. Consumers can reference it via `<Icon name="aws-s3-tables-iceberg" />` (resolves through `LogoName`). The artwork is the S3 Tables Iceberg REST glyph (bucket plus table, fill `#7AA116`), distinct from the generic `aws-s3` bucket logo.
